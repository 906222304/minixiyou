# 特性系统设计

## 一、系统概述

### 1.1 核心规则
- **创建角色时**：随机获得 3 个特性
- **特性总数**：理论上无限，设计时目标 60-100 个
- **特性强度**：微弱但有趣，强调个性而非数值

### 1.2 稀有度分级

| 稀有度 | 颜色 | 概率 | 预期特性数 |
|--------|------|------|------------|
| **普通** | 白色 | 50% | 20-25 个 |
| **稀有** | 蓝色 | 30% | 15-20 个 |
| **史诗** | 紫色 | 15% | 10-15 个 |
| **传说** | 橙色 | 4% | 5-8 个 |
| **神话** | 金色 | 1% | 3-5 个 |

### 1.3 特性类型

| 类型 | 说明 | 占比目标 |
|------|------|----------|
| **属性加成型** | 直接提升基础属性 | 30% |
| **战斗触发型** | 战斗中触发特殊效果 | 25% |
| **经济收益型** | 影响金币、掉落、经验 | 25% |
| **趣味体验型** | 有趣但无实际收益 | 20% |

## 二、特性框架

### 2.1 数据结构

```typescript
interface Trait {
  id: string;                    // 特性ID
  name: string;                  // 特性名称
  description: string;           // 特性描述
  rarity: TraitRarity;           // 稀有度
  type: TraitType;               // 类型
  effects: TraitEffect[];        // 效果列表
  conflicts?: string[];          // 冲突特性ID（互斥）
  requirements?: TraitRequirement; // 获取条件
}

type TraitRarity = 'common' | 'rare' | 'epic' | 'legendary' | 'mythic';
type TraitType = 'attribute' | 'combat' | 'economic' | 'fun';

interface TraitEffect {
  type: EffectType;
  value: number | string;
  target?: string;
  condition?: string;
}

type EffectType =
  | 'stat_bonus'           // 属性加成
  | 'stat_percent'         // 属性百分比加成
  | 'combat_trigger'       // 战斗触发
  | 'drop_rate'            // 掉落率
  | 'exp_bonus'            // 经验加成
  | 'gold_bonus'           // 金币加成
  | 'special_effect';      // 特殊效果
```

### 2.2 特性ID命名规范

```
格式: trait_[稀有度缩写]_[类型缩写]_[序号]

稀有度缩写:
- c = common (普通)
- r = rare (稀有)
- e = epic (史诗)
- l = legendary (传说)
- m = mythic (神话)

类型缩写:
- attr = attribute (属性)
- combat = combat (战斗)
- econ = economic (经济)
- fun = fun (趣味)

示例:
- trait_c_attr_001 = 普通属性特性 #1
- trait_r_combat_003 = 稀有战斗特性 #3
- trait_m_fun_001 = 神话趣味特性 #1
```

## 五、特性抽取算法

```typescript
function rollTraits(count: number = 3): Trait[] {
  const traits: Trait[] = [];
  const usedIds = new Set<string>();

  for (let i = 0; i < count; i++) {
    // 1. 决定稀有度
    const roll = Math.random() * 100;
    let rarity: TraitRarity;
    if (roll < 1) rarity = 'mythic';
    else if (roll < 5) rarity = 'legendary';
    else if (roll < 20) rarity = 'epic';
    else if (roll < 50) rarity = 'rare';
    else rarity = 'common';

    // 2. 从该稀有度池中随机选择
    const pool = TRAIT_POOL[rarity].filter(t =>
      !usedIds.has(t.id) &&
      !hasConflict(t, traits)
    );

    if (pool.length > 0) {
      const trait = pool[Math.floor(Math.random() * pool.length)];
      traits.push(trait);
      usedIds.add(trait.id);
    }
  }

  return traits;
}
```
