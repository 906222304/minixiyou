## 一、项目概述

### 1.1 产品定位

**一款参考梦幻西游的单机文字RPG游戏（主要面向手机网页端）**

- **核心灵魂**：长线养成（宠物 + 装备 + 伙伴）
- **驱动因素**：数值验证 + 效率追求 + 刷宝乐趣 + 养成满足感
- **呈现形式**：简约视觉 + 文字描述，战斗UI参考《放置江湖》小人动画
- **目标平台**：**手机网页端为主**，兼容PC浏览器

### 1.2 目标用户

- 梦幻西游老玩家，怀念经典玩法
- 喜欢养成收集类游戏的玩家
- 追求Build策略深度的玩家
- 碎片化时间游戏的手机用户

### 1.3 核心体验

```
角色创建 → 地图探索 → 战斗刷宝 → 装备打造/宠物培养/伙伴养成 → 挑战更高难度 → 循环
```

### 2.1 移动端适配策略

| 策略 | 说明 |
|------|------|
| **响应式布局** | 使用Tailwind的响应式断点，移动优先设计 |
| **触摸优化** | 按钮最小44px，防止误触，支持滑动操作 |

### 3.2 战斗系统 【MVP必需】

#### 3.2.1 阵容结构

```
最终阵容（10人） ← MVP阶段为6人

MVP阵容结构：
├── 主角位（1人） + 宠物1
├── 伙伴位1（1人） + 宠物2
└── 伙伴位2（1人） + 宠物3

总计：3人物 + 3宠物 = 6战斗单位
```

#### 3.2.2 战斗流程

```
遭遇敌人 → 显示战斗界面 → 速度排序 → 回合开始
    ↓
选择行动（自动/手动切换）
    ├── 攻击：普通物理攻击
    ├── 技能：使用门派技能
    ├── 防御：防御+50%，回复5%HP
    ├── 道具：使用背包道具
    ├── 召唤：切换宠物
    └── 逃跑：尝试逃离（Boss战/副本不可逃跑）
    ↓
执行行动 → 计算伤害/效果 → 显示结果
    ↓
敌人行动 → 检查战斗结束 → 下一回合
    ↓
战斗结算 → 经验/金币/掉落
```

#### 3.2.3 战斗特性

| 特性 | 说明 |
|------|------|
| **回合制** | 速度决定行动顺序 |
| **自动/手动** | 可切换，自动时AI控制 |
| **倍速** | 支持1x/2x/3x倍速 |
| **跳过战斗** | 暂不开放 |
| **阵法系统** | MVP预留，简化版实现 |

#### 3.2.4 伤害类型

| 类型 | 计算方式 | 特点 |
|------|----------|------|
| 物理伤害 | 攻击 - 防御 | 受物理防御影响 |
| 法术伤害 | 法攻 - 法防 | 受法防和元素抗性影响 |
| 固定伤害 | 基础值 × 等级系数 | 无视防御 |
| 真实伤害 | 固定值 | 无视一切 |

#### 3.2.5 元素系统

| 元素 | 效果 | 代表门派 |
|------|------|----------|
| 冰(水) | 减速30%，持续2回合 | 龙宫 |
| 火 | 灼烧3%HP/回合，持续3回合 | 魔王寨 |
| 雷 | 眩晕1回合 | 天宫、方寸山 |

克制关系：冰 → 火 → 雷 → 冰

### 3.4 词条系统 【MVP简化】

#### 3.4.1 词条设计（暗黑 + 梦幻缝合）

**词条类型分布：**

| 类型 | 占比 | 示例 |
|------|------|------|
| 基础属性 | 40% | 力量+10~50 |
| 百分比加成 | 25% | 攻击+3%~15% |
| 战斗属性 | 15% | 暴击率+2%~8% |
| 条件触发 | 10% | HP<30%时攻击+20% |
| 特殊效果 | 8% | 攻击时5%概率触发火球术 |
| 负面词缀 | 2% | 攻击+15%但防御-10% |

**数值范围（按品质）：**

| 词条 | 白装 | 蓝装 | 紫装 | 橙装 | 金装 |
|------|------|------|------|------|------|
| 力量 | 5-15 | 10-30 | 20-60 | 40-100 | 80-150 |
| 攻击% | 1-3% | 2-5% | 3-8% | 5-12% | 8-20% |
| 暴击率 | 1-2% | 2-4% | 3-6% | 4-8% | 6-12% |
| 暴击伤害 | 5-10% | 8-15% | 12-25% | 20-40% | 30-60% |

#### 3.4.2 洗练机制

| 操作 | 消耗 | 说明 |
|------|------|------|
| 全部重随 | 洗练石×1 + 金币 | 所有词条重新随机 |
| 锁定1条 | 锁定石×1 + 洗练石×1 + 金币 | 1条固定，其他重随 |
| 锁定2条 | 锁定石×3 + 洗练石×1 + 金币 | 2条固定，其他重随 |
| 锁定3条 | 锁定石×6 + 洗练石×1 + 金币 | 3条固定，其他重随 |

#### 3.4.3 MVP简化范围

- 品质只开放：普通、稀有、史诗
- 词条类型：基础属性 + 百分比加成 + 战斗属性
- 暂不开放：条件触发、特殊效果、负面词缀

### 3.5 宠物系统 【MVP必需】

#### 3.5.1 宠物类型

| 类型 | 定位 | 特点 |
|------|------|------|
| 攻击型 | 物理输出 | 高攻击，伤害技能 |
| 法术型 | 法术输出 | 高法攻，群体/元素技能 |
| 防御型 | 坦克 | 高HP/防御，保护主人 |
| 辅助型 | 治疗/增益 | 治疗、加状态技能 |
| 控制型 | 封印/减益 | 封印、减速、混乱 |

#### 3.5.2 宠物养成

| 功能 | 说明 | MVP状态 |
|------|------|----------|
| **捕捉** | 野外战斗中捕捉怪物 | 必需 |
| **等级成长** | 跟随战斗获得经验 | 必需 |
| **资质系统** | 决定成长上限(0.8-1.5) | 必需 |
| **亲密度** | 影响战斗表现 | 简化 |
| **合宠** | 两只宠物合成，资质融合 | 必需 |
| **打书** | 学习新技能，可能覆盖旧技能 | 必需 |
| **炼妖** | 宠物+材料提升资质 | 必需 |
| **进化** | 达到条件进化为更高级形态 | 后续 |
| **内丹** | 额外属性加成 | 后续 |
| **坐骑技能** | 特殊战斗技能 | 后续 |

#### 3.5.3 捕捉机制

```
捕捉条件：
├── 目标HP < 30%
├── 拥有捕捉道具
└── 捕捉率计算

捕捉率 = 基础20% + (30%-HP%)×1.5% + 异常状态加成×10% + 道具加成 - 稀有度惩罚
```

#### 3.5.4 合宠机制

```
合宠规则：
├── 两只宠物合成
├── 资质取随机值（在两只宠物资质范围内）
├── 技能池合并，随机保留
├── 有概率获得额外技能槽
└── 稀有度可能提升
```

#### 3.5.5 打书机制

```
打书规则：
├── 使用技能书学习新技能
├── 技能槽未满：直接学习
├── 技能槽已满：随机覆盖一个技能
├── 高级技能书有更高覆盖低级技能概率
└── 必定成功的保护机制（可选）
```

### 3.6 伙伴系统 【MVP简化】

#### 3.6.1 伙伴定位

- **与主角一样配置**：可穿戴装备、学习技能、升级
- **有门派限制**：复用12门派系统
- **有个性表现**：对话、剧情、好感度

#### 3.6.2 伙伴与宠物区别

| 对比项 | 宠物 | 伙伴 |
|--------|------|------|
| 装备系统 | 无 | 完整9槽位 |
| 技能系统 | 宠物技能池 | 门派技能树 |
| 门派限制 | 无 | 有 |
| 获取方式 | 野外捕捉 | 剧情解锁/商店/副本等 |
| 个性表现 | 无 | 有对话、剧情、好感度 |

#### 3.6.3 伙伴获取来源

| 来源 | 优先级 | MVP状态 |
|------|--------|----------|
| 剧情解锁 | 最高 | 必需 |
| 副本掉落 | 高 | 后续 |
| 任务奖励 | 中 | 后续 |
| 商店购买 | 中 | 后续 |
| 地图探索 | 低 | 后续 |
| 抽卡召唤 | 低 | 后续 |

#### 3.6.4 MVP伙伴数量

- **MVP阶段**：3个伙伴（剧情解锁）
- **完整版预期**：15-20个

#### 3.6.5 伙伴羁绊系统

特定伙伴组合激活羁绊效果：

| 羁绊类型 | 示例 |
|----------|------|
| 属性加成 | 孙悟空+猪八戒：全队攻击+5% |
| 技能加成 | 同门派伙伴：门派技能伤害+10% |
| 特殊效果 | 取经组合：战斗开始回复10%HP |

## 六、数值设计原则

### 6.1 属性设计

```
五大基础属性：
├── 力量(STR)：物理攻击、物理暴击
├── 灵力(INT)：法术攻击、法术防御、MP上限
├── 体质(VIT)：HP上限、物理防御、恢复效果
├── 敏捷(AGI)：速度、闪避、暴击率
└── 魔力(WIL)：MP上限、法术暴击、异常抵抗
```

### 6.2 战斗属性

```
战斗属性 = 基础属性 × (1 + 装备加成%) + 装备固定值
最终属性 = 战斗属性 × (1 + 状态加成%) × (1 + 羁绊加成%)
```

### 6.3 伤害公式

```
物理伤害 = (攻击力 - 防御力) × 技能倍率 × 暴击倍率 × 随机波动(0.9-1.1)
法术伤害 = (法攻 - 法防) × 技能倍率 × 元素倍率 × 暴击倍率 × 随机波动
固定伤害 = 基础值 × 等级系数
```
