## 四、门派克制关系

```
大唐 → 龙宫 → 盘丝 → 方寸 → 魔王 → 化生
  ↑                                      ↓
地府 ← 天宫 ← 狮驼 ← 五庄 ← 普陀 ← 女儿
```

克制片段（3个门派循环）：
- 大唐克龙宫、盘丝、方寸
- 方寸克魔王、化生、普陀
- 普陀克女儿、五庄、狮驼
- 狮驼克天宫、地府、大唐

## 五、技能设计要点

### HP要求
- 横扫千军：HP > 50%

### 休息回合
- 横扫千军：使用后休息1回合
- 鹰击：使用后休息1回合
- 后发制人：使用后休息1回合

### 变身系统（狮驼岭特有）
- 必须先变身才能使用部分技能
- 象形使用后取消变身

### 封印技能
- 命中率受技能等级、修炼影响
- 持续回合随等级提升

### 固定伤害
- 不受防御影响
- 夜晚效果增强（地府）
