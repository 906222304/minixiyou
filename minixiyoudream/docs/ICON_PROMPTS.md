# AI Icon Generation Prompts

This file contains prompts for generating Q-style game icons using AI image generators (DALL-E, Midjourney, Stable Diffusion, etc.).

## Style Guidelines

All icons should follow these style guidelines:
- **Q-version (Chibi) style**: Cute, rounded characters
- **Color palette**: Bright, saturated colors with subtle gradients
- **Size**: 128x128 or 256x256 pixels recommended
- **Background**: Transparent PNG
- **Border**: Optional subtle glow or shadow for depth
- **Style reference**: Fantasy Westward Journey (梦幻西游) mobile game icons

## Usage Instructions

### For DALL-E 3:
1. Go to ChatGPT or DALL-E interface
2. Copy and paste each prompt
3. Generate and download as PNG
4. Resize to appropriate dimensions

### For Midjourney:
1. Add "--style cute --q 2 --v 6" to end of prompts
2. Use "--no background" for transparency
3. Example: `[prompt] --style cute --q 2 --v 6 --no background`

### For Stable Diffusion:
1. Use a chibi/anime model
2. Add negative prompts: "realistic, photorealistic, 3d render, dark, gritty"
3. Use transparent background extension
