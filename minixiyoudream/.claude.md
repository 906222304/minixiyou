# MiniXiyouDream 项目上下文

## 技术栈
| 类别 | 技术 | 版本 |
|------|------|------|
| 框架 | React | 19.x |
| 语言 | TypeScript | 5.8.x |
| 构建 | Vite | 6.x |
| 状态 | Preact Signals | 2.x |
| 存储 | Dexie.js | 4.x |
| 样式 | Tailwind CSS | 4.x |

## 目录结构
```
src/
├── types/          # TypeScript 类型定义
├── constants/      # 游戏配置数据
├── signals/        # Preact Signals 状态管理
├── services/       # 业务逻辑服务层
├── components/     # React 组件
├── db/             # Dexie.js 数据库
└── styles/         # 全局样式
```

## 常用命令
```bash
pnpm dev        # 启动开发服务器
pnpm build      # 构建生产版本
npx tsc --noEmit # TypeScript 类型检查
```

## 已完成系统
- 角色系统（种族+门派+特性）
- 战斗系统（6人阵容，自动/手动）
- 装备系统（9槽位，品质，宝石镶嵌）
- 宠物系统（捕捉，等级，资质）
- 伙伴系统（羁绊，好感度）
- 地图系统（30+地图，7区域）
- 副本系统（多层副本，奖励）
- 剧情系统（12章66个主线任务，16个日常任务）
- 成就系统
- 存档系统（IndexedDB）

## 核心规范
- 使用 Preact Signals 管理全局状态
- 配置数据放在 src/constants/
- 业务逻辑放在 src/services/
- 类型定义放在 src/types/
