# MiniXiyouDream 迷你西游梦

> 西游题材单机文字 RPG 游戏

## 快速开始

```bash
npm install
npm run dev
```

## 已完成系统

- 角色系统（3种族、12门派、特性随机）
- 战斗系统（6人阵容、自动/手动、倍速）
- 装备系统（9槽位、品质、宝石镶嵌）
- 宠物系统（捕捉、资质、出战）
- 伙伴系统（羁绊、好感度）
- 地图系统（30+地图、7区域）
- 副本系统（多层副本、奖励）
- 剧情系统（12章66主线任务、16日常任务）
- 成就系统
- 存档系统（IndexedDB）

## 技术栈

- React 19 + TypeScript 5.8
- Vite 6 + Tailwind CSS 4
- Preact Signals + Dexie.js
