# 初始化项目

初始化 MiniXiyouDream 项目的 Vite + React + TypeScript 环境。

## 执行步骤

1. 进入项目目录
2. 使用 pnpm 创建 Vite React TypeScript 项目
3. 安装必要依赖
4. 配置项目

## 依赖列表

### 生产依赖
- react ^19.0.0
- react-dom ^19.0.0
- @preact/signals-react ^2.0.0
- dexie ^4.0.0
- lucide-react ^0.400.0

### 开发依赖
- @types/react ^19.0.0
- @types/react-dom ^19.0.0
- typescript ^5.8.0
- vite ^6.0.0
- @vitejs/plugin-react
- vite-plugin-pwa ^0.20.0
- tailwindcss ^4.0.0
- @tailwindcss/vite
- eslint ^9.0.0
- prettier ^3.0.0

## 验收标准
- [ ] `pnpm dev --host` 可启动
- [ ] 手机可访问
- [ ] TypeScript 编译无错误
